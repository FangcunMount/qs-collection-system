# 全局受试者选择

首页、医学量表目录与列表、人格与行为目录、人格模型详情、报告列表、待填写任务和“我的”使用同一顶部受试者选择栏。选择写入现有 TesteeStore，跨页面与返回页面沿用；不新增第二份持久状态。

- 多档案未选择时明确显示“选择受试者”，不默认代选第一人。单档案仍沿用原自动选择。
- 新普通测评优先使用有效全局选择；有明确入口受试者或机构任务时，仍使用入口的固定身份。
- 填写前的“为谁测评”是本次保存对象的确认，可通过既有选择行为更新全局选择。开始填写后沿用已冻结提交契约。
- 已打开的单份报告、AI 解读、答卷与机构任务不提供全局切换栏，不改变其关联身份。
- 报告列表切换时重建成员查询状态，清空旧列表与筛选弹层；成员、请求版本或登录会话不匹配的迟到响应不提交。
- 移除档案或退出登录时沿用现有 Store 校验和清理。选择器不独立请求或缓存家庭档案。
- 底部导航仅保留首页、量表、报告、我的；移除中央扫一扫按钮和样式。机构二维码入口协议及异常入口的重新扫码行为继续使用原实现。

## 验收

代码回归覆盖：跨页面切换同步、未选择不代选、管理入口不改变选择、档案移除与清空、普通测评继承、机构身份优先、报告列表迟到响应和分页隔离、四项底部导航。

模拟器固定样本核对首页与报告列表的顶部位置和跨页面选择；真实账号、真机切换、填写与报告回看另行验收。固定样本或 CI 通过不等同于正式版发布。
