# 医学量表报告：现有版式精修

医学报告保留现有蓝白视觉、居中总分及风险结论、完整 AI 补充卡片，以及“概览 → AI → 趋势 → 因子分析／详细建议”的阅读顺序。

## 实现边界

- 样式集中在 `MedicalReportPresentation.less`，由 `.medical-report-shell` 限定；共享卡片和按钮在其他报告中的样式不变。
- 复用现有设计 token，增加医学报告总分字号 token；调整阅读字号、卡片间距、圆角、轻边框及图表切换按钮。
- 风险徽章仅优化分隔符；因子图表增加标准报告结论说明。风险颜色、评分、建议正文、默认雷达图及切换行为仍来自原实现。
- 不变更鉴权、AI 状态、报告加载、历史趋势计算、缺失值处理或完成按钮去向。

## 验证边界

相关报告生命周期、趋势、标签与默认图表回归，以及医学报告 mapper、严格类型、UI 边界、资源与微信构建检查已通过。CI 仍需在对应 PR 核对。

微信开发者工具使用实际组件和虚构数据核对首屏、趋势摘要与详细建议；未调用生产接口。隔离预览的原生图表画布未成功绘制，不能宣称图表视觉已通过。合并前仍需在正常小程序项目核对雷达／条形／散点实际绘制、长因子标签、固定按钮及 iOS／Android 真机；正式发布单独验收。
